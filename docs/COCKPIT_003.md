# COCKPIT 003 — FLOW TOUCH
Opt-in /play/?mode=marrow&cockpit=1&touch=flow&vehicle=vector. Existing single/dual/desktop/DS4 paths unchanged. Explicit 12 CSS px vertical-dominant upward gesture activates .48 cruise for the lifetime of that contact only. Subsequent deliberate vertical motion adjusts cruise; downward motion reaches zero then applies brake. Horizontal motion resets vertical gesture accumulator, so carving/jitter cannot accumulate throttle. Release/cancel/focus/menu/orientation reset all touch intent. No unattended or persistent cruise. Neutral is input neutral, not instantaneous physical stop. Vehicle-relative horizontal origin rebases at saturation, vertical origin follows thumb; separate carve sensitivity. Flow-only speed-dependent steering rate and coast tangent-velocity rotation reuse existing 120 Hz control and damping, contact and landing solver unchanged. Flight actions are sequential single-contact hold gestures: release drive, hold Lift, release and hold Land; no flight latch. One pause/settings menu contains research and secondary controls; menu stops simulation outside inspection. Portrait broad bottom zone; landscape dominant-side zone. No physical device acceptance claimed.
