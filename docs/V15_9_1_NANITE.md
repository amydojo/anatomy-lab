## Pipeline and integration contract
1. Run the existing pinned source qualifier: `python3 scripts/qualify_unity.py --output unity-qualified`. Then run `node --max-old-space-size=4096 scripts/build_unity_geometry.mjs unity-qualified unity-nanite`. The output directory must not exist. Exact GLBs remain separately available from unity-qualified; publish neither directory automatically.
2. Builder uses all 143 source labels (not conventional 206 independently segmented bones), original source hashes and RESIDENCY display transform. Twelve-pass offline edge-collapse trial uses existing 1.2%/0.4% correspondence and topology checks. Rejected tiers fall back to exact-display. Independent 512-area-sample + 6 extrema bidirectional point-to-triangle audit per candidate. Record all rejections, lossless gzip round-trip, per-tier counts, exact hashes, packed buffer sizes and budget failures. Do not treat samples as an exact Hausdorff result.
3. WORLD must pin SHA-256 of both immutable source and derivative manifests from a reviewed artifact and verify bytes before calling validateManifest. Source root and derivative root are separate, same-origin directories. Do not expose unreviewed derivatives as clinically qualified. The schema is body-live-unity-geometry-1. Structure IDs remain canonical source IDs. Exact source is separately fetched/verified by UnityGeometrySession.exact(id,signal); parse it with BodyVHF.parse(..., true, true) before source-backed picking. Approximate display picking must be explicitly distinguished.
4. Import UnityGeometrySession, createGeometryWorker, bindGeometry from assets/atlas/unity-residency.mjs. Construct worker, then session with {gl,manifest,source,root,exactRoot,prepare:worker.prepare}. Invoke step(camera,selected,visible) from host draw scheduler without overlapping calls; render ledger.resident handles only. Use same RESIDENCY camera convention and viewport dimensions. Host owns input, culling, camera, draw scheduling, context loss/rebuild, selected exact CPU cache, retry UI, and teardown (session.dispose + worker.close). Set weight attribute to constant zero and restore legacy vertex attribute state before other draw paths. Budget reserves staging plus resident bytes; no replacement becomes visible until completed and measured WebGL BUFFER_SIZE matches expected allocation. Protect currently visible parents; failed allocations preserve old geometry. If coverage itself cannot fit, surface failed gate rather than hide anatomy. A large exact selection can be denied by budget; CPU exact source remains available separately. The adapter does not integrate an existing scene by itself.
5. Cluster experiment partitions large exact meshes by centroid longest-axis median, validates every original face and exact shared coordinates, measures duplicated vertices and compressed bytes. It does not publish or authorize independently mixed LOD cluster transitions; whole-structure swaps only. Independent boundary-locked hierarchical decimation remains future work.
6. Positions remain Float32; normals are SNORM8 (visual shading difference not yet reviewed). GPU layout 16 B/vertex versus 28 previously, plus actual index width. Compressed BLD1 payload stores float32 positions and 16/32-bit indices; gzip is lossless. Position quantization and meshopt/Draco not enabled pending independent error, decoder, and licensing evaluation.
