# V15.0 Expedition controller prototype
Stacked on V14.3, preview only. Pair a DualShock 4 to a Mac, open the atlas in Chrome, click Controller mode, press a button then release. Optional initial route: /atlas/?studio=connective&expedition=1. TV output is via Mac HDMI/AirPlay, not native PS4 execution.
Left stick pan, right stick orbit, L2/R2 zoom out/in, Cross center exact pick, Circle camera Back in knee studio or clear selection/return to body, Square isolate selected knee structure, Triangle Dive selected knee structure, R3 recenter, D-pad up/down layer on non-studio details, left/right region from overview. No AI calls yet. Controller mode does not modify any anatomical sources or promise full-body tissue coverage.
Release checks: Node tests, browser regression, exact-SHA preview, physical DualShock 4 pairing, neutral drift, camera continuity, deep zoom, disconnect/reconnect, pointer coexistence and TV legibility. No production merge before stacked dependencies pass. Standard mapping required; unsupported devices are ignored.
