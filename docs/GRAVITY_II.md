## Contract

Renderer owns camera and projection; reset on discontinuity, focus loss, explicit recovery, source or coordinate-space change. No changes to shared shortcuts or audio/capture/typography. snapshot(camera,t,spaceId) returns versioned editable keyframe (timestamp supplied by caller); renderer/recorder owns sampling and serialization. SOMATIC can use intent/shape and matrixUnits independently without adopting Atlas camera. Matrix helper supports conventional non-skewed perspective/orthographic column-major matrices, view-space negative Z; current live adapter uses Atlas's exact fixed-eye projective equation. Units are display units per CSS pixel, not mm. Selected point target-depth correction smoothed over 120 ms; proximity heuristic is not surface clearance. Profile velocity integrates exponential response analytically, caps dt at .05s, discards >.15s gaps; release decays faster at macro. Anchor correction rejects bounds violations; explicit panning overrides anchor.
