# COCKPIT 001
Opt-in /play/?mode=marrow&vehicle=vector&cockpit=1. Touch mode auto starts single when maxTouchPoints <=1, otherwise dual; explicit &touch=single or &touch=dual overrides. Actual concurrent touch contacts recorded separately from reported capability. No Tesla browser hardware validation; parked only, no vehicle APIs or vehicle control. No flow/SLIPSTREAM live enablement; legacy locomotion retained, adaptive/review buttons disabled. Existing VECTOR pinned SHA, loader/cache, original fallback, GYROSCOPE rig and physics untouched.
Dual: floating steer left, vertical pedal right (drag up throttle, down brake), independent pointer IDs; lift/land/grind held via context buttons, free area drag camera. Single: joystick magnitude drives, direction steers; pedal still brakes/straight drives; actions sequential, no latched throttle. Release neutral; actual deceleration governed by existing sim. Settings persist local, handedness mirrors, scale/opacity/sensitivity bounded. Clear on cancel/lost capture, focus/visibility/resize/orientation/settings/inspection/exit. Touch controls scoped to MARROW surface. Desktop/gamepad mapping unchanged when disabled. With touch active merges analog intent into existing MARROW stick/push/brake/action fields, no automatic boost.
Test real parked Tesla concurrent touch (advertised maxTouchPoints not proof), iPad, iPhone, desktop; actual hardware separate from simulated pointer tests. No guarantee browser chrome gestures can be intercepted. Existing simulation/geometry gates are inherited, not newly qualified.
