# SOMATIC 001 — isolated artistic laboratory
Open /somatic/ explicitly. No atlas assets or production entrypoints changed. Reuses BodyVHF pinned manifest/GLB verification and standard BodyExpedition input shaping. Default cervical spine; separate regional BoneHub views and Denver right knee, never registered or blended. No source vertices edited; display-only transforms, depth cuts, color, and opacity. No clinical inference. Source citations: BoneHub revision 53bd62452ae3fc34ba0fa6188517cd8ca9bf4a10, DOI 10.57967/hf/10464; Denver DOI 10.56902/COB.vh.2022.0; both CC BY 4.0.
## Performance
Left stick pan, right orbit, L2/R2 zoom, D-pad left/right fader selection, up/down steps, L1/R1 continuous adjustment, square/triangle looks, cross reveal, circle neutral, R3 recenter, Options clean output. Escape/show controls exits clean output. Fullscreen support browser dependent; AirPlay via OS mirroring. The standalone shader uses actual depth-tested text plane, static surface grain, optional previous-frame accumulation and surface alpha (not physically correct multilayer transparency). Frequency bands map bass to lighting and bounded screen drift, mids to opacity, highs to static grain. No strobe, no rapidly varying luminance effects; reduced motion disables audio modulation/trails. Audio explicitly opted in, never uploaded; microphone not routed to speakers; stop/pagehide/hidden stop tracks. File audio loops locally. Takes capture camera, parameters, bands and tissue at ~10 Hz for up to 10 min/6000 samples; replay is in-session only; JSON export is data, not audio/video. Stills export composite. No import or video recording yet.
