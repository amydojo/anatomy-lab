## API and lifecycle
Import openUnityGeometryProvider, bindGeometry, overviewPreflight, PROVIDER_VERSION from assets/atlas/unity-residency.mjs. Version 1.1.0. Source and derivative roots are separate absolute/same-origin directories; pass independently reviewed sourceHash and derivativeHash (not values inferred from a downloaded manifest), sourceUrl, derivativeUrl, gl, root, exactRoot. The factory verifies both raw manifest digests, source binding and exact GLB identity before creating a worker. The low-level session constructor is for controlled fixtures; do not pass unverified network objects. Never use an unreviewed manifest as a pin.

The default 32 MiB ceiling includes all NANITE committed+staged geometry; 4 MiB is reserved for transition headroom, leaving 28 MiB steady. This is an engineering policy, not a guarantee every replacement fits. Other renderer buffers, CPU caches and driver overhead are outside this ledger. Preflight fails closed on incomplete whole-world coverage. allowPartialDiagnostic:true is an explicit diagnostic-only escape hatch; never present partial coverage as UNITY. Payload gate remains separate. Current reviewed artifact: 73.81 MiB overview, 42.69 MB geometry payload; cannot activate a production full skeleton. Do not raise the budget or drop labels to mask this.

- step(camera,selected,visible): asynchronous, at most one staged request; host calls from draw scheduler; continue rendering existing handles while waiting. The host must invalidate/draw after completion, and must not busy-loop when denied. Missing visible structures are prioritized before refinements; no visible parent removed until replacement is fully uploaded. A failed reservation leaves unrelated handles intact; eligible LRU eviction only after a viable allocation plan and 5-second dwell.
- getDrawables(): read-only-by-convention snapshot {id,level,handle,bytes}; bindGeometry(gl,handle,{position,normal,weight}) binds FLOAT32 positions and SNORM8 normals at 16-byte stride. Use gl.drawElements with handle.count/indexType. Restore legacy attribute state on switching paths.
- touch(id,now): call after drawing, using same performance.now clock as session. diagnostics(): reports preflight, budget, headroom, committed/staged/peak bytes, denied requests, resident/pending counts and failures. Log actual host timings, draw coverage and input latency separately.
- exact(id,signal): independently hash-check original GLB bytes; host parses with BodyVHF.parse(buffer,{structures:[{...sourceRecord,tissue:'Bone'}]},true,true) and uses exact-source picking. CPU exact cache and BVH are host-owned; distinguish approximate display picks. Cancel outstanding exact fetch via caller signal. No per-bone mirroring, recentering or physical-unit assertion.
- cancel(): abort in-flight worker/GL upload; parent retained, cancellation does not blacklist geometry. retry(): clear failed request keys; a terminated worker requires fresh provider. dispose(): cancel in-flight work, delete resident GL handles and close worker; idempotent use expected by host. On webglcontextlost, preventDefault, stop draw scheduling, dispose provider, discard handles and keep camera/controller state outside provider. On restored context rebuild shader state, reopen with identical pins, resume coverage and selection. Never reuse lost handles. Browser context recovery still needs device verification.

Camera uses the existing RESIDENCY display transform [(240-x)*.005,(z-1000)*.005,(y-235)*.005], same yaw/pitch/target and actual canvas width/height/frameSpan/zoom; physical spacing unconfirmed. No automatic registration or Denver fusion.

## Measured performance and engineering decision
Full source 6,070,400 triangles; overview 4,491,656; 82 overview/28 regional/33 exact fallbacks. Fallbacks consume 55,530,000 bytes. Eight largest exact fallbacks dominate. Reconstructed spatial partitions (16,384 triangles max) across these eight preserve all original indexed faces and seam coordinates. Cranium: 64 clusters, 18,999 seam edges, 18,831 unique locked vertices; 37,968 locked vertex instances out of 433,877. Switching those eight to exact 16-bit-index partitions would lower the global packed overview from 77,390,560 to 63,657,792 bytes (60.71 MiB), still fails. No partitioned rendering or mixed LOD enabled. Compression/transport and independent topology-aware simplification of the largest fallback structures are the next gate, not further provider expansion. Preserve existing tolerances.
