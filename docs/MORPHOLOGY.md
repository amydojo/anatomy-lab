# MORPHOLOGY / provider v1
Independent BP3D reference, never VHF fusion. Source-lock pins full public upstream atlas (all chunk Git blob hashes and known SHA-256) and 47-part OMFAtlas facial derivative. Acquisition verifies bytes, source blob, known SHA, finite xyz, index bounds, per-part raw SHA-256 and native bounds. Outputs exact packed positions/indices from the pinned upstream derivative, no simplification or individual repositioning. The upstream derivative is not the original MRI segmentation. BP3D 4.0 CC BY 4.0, BP3D 3.0 OMF extension CC BY-SA 2.1 JP. Retain attribution and same license on facial derivatives. Upstream registration is experimental; no validation of clinical motion/attachment. Existing reduced facial overlay is separately named. Z-Anatomy CC BY-SA 4.0 considered, not acquired. Denver publication is lower-extremity-only; no upper-body completion asserted.
## Reproduce
python3 scripts/acquire_morphology.py; inspect assets/atlas/morphology/acquired/inventory.csv (entire upstream index) and catalog.json (selected actual meshes). Region classification is conservative source name/system metadata, ambiguous labels excluded. Full target list not guaranteed. No skin-to-bone depth taxonomy inferred.
## SOMATIC handoff
Import createProvider from /assets/atlas/morphology/provider.mjs. provider.discover() returns ids, source spaces, tissue lists and counts. provider.stream(id,{tissues,signal,maxBytes}) yields verified packets, typed positions/indices, stable IDs, native bounds where available, source license, category, material color, timing. provider.loadSomatic(id,{signal}) returns existing SOMATIC-compatible parts array with sourceInfo including manifestHash; same shape as BodyVHF loaders, no engine edits. Consumer owns GPU disposal and should preserve previous source until staging succeeds. Use distinct sourceKey; do not replay a take against a different manifestHash. Do not combine BP3D with BoneHub or Denver. Artistic material override is consumer state, never mutate scientific source metadata. Existing SOMATIC's fixed category select needs dynamic categories if adding organs/arteries etc.
## Viewer
/atlas/morphology/ includes independent source specimen chooser, multi-tissue toggles, color, alpha, isolation, artistic clipping, controller orbit/zoom/tissue cycling. Approximate transparency sort (not order-independent), no anatomical depth inference. 96 MiB combined staged GPU buffer budget, 32 MiB payload cap; GPU buffer size and CPU submission are estimates/proxies, not GPU completion or AirPlay responsiveness. No production promotion.
