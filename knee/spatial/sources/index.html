Alignment and movement contract

The femur remains in a static frame; the lower-leg group (tibia, fibula, and simplified menisci) rotates around a fixed illustrative transverse pivot. The patella follows an approximate visual path. Crossing and collateral ligaments are rendered between manually placed attachment proxies. These lines illustrate spatial relationships; they are not measured entheses, tissue simulations, surgical planning data, or physically accurate tracking.

Coordinate convention used only within this prototype: +Y proximal, +Z anterior, +X lateral. A perspective orbit camera controls view orientation; the flexion slider controls only the illustrative joint pose. The pivot and soft-tissue routes are not claims of anatomical measurements.

Accuracy gates before importing a real model

  1. Obtain the official dataset and record exact file URLs, hash digests, license terms, dataset release and structure identifiers.
  2. Validate femur, tibia, fibula and patella as a single coordinate frame from the same reference specimen. Check side, superior-inferior orientation, and units.
  3. Inspect joint contact surfaces and anatomical landmarks; preserve original mesh files and maintain a reproducible transform log.
  4. Have qualified anatomy reviewers assess geometry, soft-tissue attachments and correspondence before labeling a clinical-grade or anatomically accurate model.
  5. Only then add kinematics tied to sourced landmarks and disclose whether movement is generalized or measured.

Technical features verified in software

Custom perspective mesh projection, explicit 3D vertex transformations, triangle visibility sorting, mouse and touch orbit, two-pointer pinch zoom, flexion pose control, structure selection, opacity peeling, reduced-motion handling, keyboard-operable sliders and structure list, mobile inspector and fallback link to the original V4 knee. No external CDN or WebGL dependency is required, and the engine does not perform any tissue stress or sensory diagnosis calculation.
